# Feature modules

This directory contains high-level product documentation for the major areas of the SahKaar platform.

## Included feature documentation

- Worker verification and onboarding
- Booking and scheduling
- Geo-dispatch and local matching
- Payments and escrow workflows
- Reviews and trust
- Admin dashboards and governance
- Worker welfare and insurance
- Demand forecasting and planning

These documents are written to explain the product from a customer and business perspective rather than exposing deployment architecture or private operational details.

For the main project overview, see the root [README.md](../README.md).
